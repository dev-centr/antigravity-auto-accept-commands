= Antigravity Auto-Accept Extension

Cursor / Antigravity status-bar toggle to auto-accept agent action requests (`run_command`, browser, file edits).

== About The Project

The *Antigravity Auto-Accept* extension adds a status bar item that lets you quickly enable or disable automation for agentic tools. It targets `run_command` calls, browser interactions, and file edits.

File edits (diffs) are **disabled by default** and must be enabled explicitly in settings.

=== Features

* *Status Bar Toggle*: icon to switch auto-accept ON and OFF.
* *Smart Synchronization*: syncs preferences with Antigravity `chat.tools` configuration.
* *Customizable Settings*: fine-grained control over which tool types are auto-accepted.
* *No Bloat*: no sidebar icons or extra panels — status bar and Settings UI only.

== Getting Started

=== Installation

1. Create a folder in your VS Code / Antigravity extensions directory: `%USERPROFILE%\.antigravity\extensions\antigravity-auto-accept`.
2. Copy `package.json` and `extension.js` into that folder.
3. Restart Antigravity.

=== Quick Start

1. Look for the status-bar icon (bottom right).
2. Click it to toggle *Auto-Accept*.
3. When highlighted, Antigravity executes approved tool types without prompting (except file diffs unless enabled).
4. Click again to return to manual approval.

== Usage

=== Configuration

Settings live under the `antigravity.autoAccept` namespace:

`antigravity.autoAccept.enabled`::
Global toggle for all auto-acceptance. Default: `true`

`antigravity.autoAccept.runCommands`::
Auto-approve `run_command` when the global toggle is ON. Default: `true`

`antigravity.autoAccept.fileEdits`::
Auto-approve file edits (diffs). Default: `false` (review diffs manually)

`antigravity.autoAccept.browserActions`::
Auto-approve browser interaction calls. Default: `true`

=== Why manual diffs by default?

Automation is powerful but risky. Keeping `fileEdits` off by default ensures you can review code changes before they land in the workspace.

=== Reference

The extension uses VS Code `workspace.getConfiguration` to update:

* `chat.tools.terminal.autoApprove`
* `chat.tools.edits.autoApprove`
* `chat.tools.global.autoApprove`
