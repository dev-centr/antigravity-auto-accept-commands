## About The Project

Automatically accept run commands in Google Antigravity with a status bar toggle.

### Features

- **Status Bar Toggle**: $(zap) icon to quickly switch between auto-accept ON and OFF.
- **Customizable**: Settings to choose which actions to auto-accept.
- **Privacy First**: File diffs are manual by default.

## Installation

Install from the VS Code / Cursor marketplace, or build from source in this repository.

## Usage

Click the Status Bar icon to toggle automation. Use the command palette and search for "Antigravity: Configure" to change detailed settings.

### Settings

- `antigravity.autoAccept.enabled`: Global toggle.
- `antigravity.autoAccept.runCommands`: Auto-approve terminal commands.
- `antigravity.autoAccept.fileEdits`: Auto-approve edits (Default: OFF).
- `antigravity.autoAccept.browserActions`: Auto-approve browser tools.
